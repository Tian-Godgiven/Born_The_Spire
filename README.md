## 简介

墙内的脉搏声停止，尖塔已然荒废，野兽、植物、失落的造物与被遗弃者徘徊在残桓断壁间。杳无人烟的塔底之下，已死高塔扎根的深处，响起了混沌的心跳。启程去唤醒这座高塔吧！

## 内容

1. 以《杀戮尖塔》为基底，搭配原作的创意，这是一款永久免费的同人游戏
2. 击败敌人并将其吞噬，同化得到种类各异的器官，不断强化角色能力，你还可以使用资源来多次升级器官
3. 战斗中随机抽取器官提供的卡牌，组建各具特色的牌库
4. 没有局外成长，但是每一局都可以解锁初始携带的器官，以更符合你心意的开局启程
5. 几乎完全靠数据驱动！
6. 我们尽可能地支持mod创作，无论你是0编程经验小白，AI糕手还是超级大佬，我们欢迎每一个人为这款游戏添砖加瓦！
