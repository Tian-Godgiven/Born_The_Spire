# 场景手册

面向 AI 与 Mod 开发者的场景式教程集。

## 定位

    开发指南（父目录） — 「加个新卡牌需要动哪些文件、字段有哪些」
    场景手册（本目录） — 「我要做出 XX 效果的卡牌，具体数据长什么样」

场景手册每一份都基于真实代码素材，模板复制即可用。

## 使用建议

新会话开始想实现某种效果，按下面顺序找入口：

    先看《新内容开发清单》确认哪些文件要动
    在本目录找匹配的手册，找场景编号
    复制数据模板，替换 label / key / describe / 数值
    如果卡在诡异行为上，翻《常见错误排查手册》

每份手册末尾都列了「相关文档」，需要更深入时按链接跳。

## 与其他文档的关系

    参考/ — 引擎原理，场景手册引用它解释「为什么这么写」
    开发指南/ — how-to，场景手册是这个层级的「按用例组织」变体
    子系统/ — 各专门功能的完整规格，场景里出现新概念时跳过去看

## 维护约定

    每份手册都基于真实 organList / cardList / relicList / stateList / enemyList 的素材
    发现引用的 key 已删或改名时更新示例
    新增高频场景可以往对应手册末尾加，或如果是跨类型模式（比如"塞卡到手牌"），加到常见错误手册
