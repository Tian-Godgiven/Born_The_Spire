# 玩家友好设计

写给加卡、器官、敌人的人。

器官规则必须对称：Boss 和玩家拿到同一颗，行为和卡必须一样，禁止 `if 玩家 / if 敌人`。本文管另一件事：**同一套规则下，效果类型要让玩家拿到更值，敌人拿来打人时要留反制。**

不写两套逻辑，靠选对效果类型。

---

## 为什么同样数字不对等

玩家大约 50 生命，整局一次机会。敌人 90～180 生命，死了就死了，下一场换人。

同一层中毒
    玩家会在几回合内被磨死，几乎挡不住
    敌人只是掉一层皮，战斗往往在毒跳完之前就结束了

同一点费用
    玩家每回合 3 费，费用就是构建的骨架
    敌人按行为表出牌，费用基本是装饰

同一张抽牌
    玩家靠抽牌把器官卡转起来
    敌人目前几乎没有「手牌运转」，抽牌接近空效果

同一场战斗里的永久增益
    玩家带进下一场，越积越厚
    敌人只活这一场

所以：**对称的是规则，不对称的是价值。** 写内容时把价值压到玩家这边，把「没反制的疼」从敌人那边拿掉。

## 对玩家不友好

这些写法通常让敌人手里更狠、玩家偷到不值，或让玩家没得做。

回合固定、不可防的伤害
    例如回合开始给玩家上毒。不占敌人行动，挡不了，越打越叠。现行已从菌网拿掉。

把威胁做成被动而不是卡
    敌人每回合白嫖一次；玩家同化后也是被动，没有「什么时候打」的决策，还可能在自己身上更疼（中毒、反伤）。

同样数值的持续状态两边套
    中毒、燃烧这类按层跳的不可防伤害，给玩家是死刑，给敌人是挠痒。在体系重做之前，敌人侧少给、改成卡、数值压低。

用费用平衡敌人卡
    敌人 2 费和 0 费打出来一样。玩家却要付那 2 费。结果是：这张卡在 Boss 战里不贵，偷到手之后变砖。

高费诅咒 / 垃圾牌
    塞进玩家牌堆却打不出去（高费、或 cannot-play），等于强制占手 + 触发惩罚。玩家没有「花资源清掉」的选择。孢子曾经 4 费，已改 1 费打出消耗。

强效果挂在敌人 `cards` 上、器官拿不到
    对称被打破：打赢了同化不到这场最有趣的那张。不想掉的用 `drop: false` 或真专属；想让玩家用的挂器官。

长线滚雪球且玩家无法打断
    每回合叠层、层数永不掉、跨越多回合 Boss 战。玩家生命薄，先被滚死。

## 可以改善的手段

威胁改成行动
    上毒、爆发改成卡，占敌人一动。玩家能看意图、能格挡、能决定这回合是否换血。菌网改为只提供加毒卡，就是这一条。

0 费
    敌人出 0 费毫无损失，玩家拿到等于白打。平衡请用「效果小」「消耗」「每场限次」，不要用费用卡玩家。

抽牌、能量、洗牌
    现在几乎只对玩家有意义。可以大胆给，作为器官独立收益（没有联动时也不是废器官）。

永久增益
    持有期间加力量、加费、加生命上限。敌人享用一场，玩家带整局。

器官升级 / 卡牌锻造的质变
    1 级能用，3 级变一套。玩家愿意把材料砸进去；敌人默认 1 级（`drop: false` 的开战高等级是例外，且不进同化）。

输出放大 + 自身减免
    例如「施加中毒 +1，自身受到中毒伤害减半」。规则仍对称。玩家组毒流时既更疼别人、又不怕反噬；敌人只有自己那一套，叠不深。

效果拆给不同怪物，靠玩家连携
    不同种类的毒、不同种族的标记，单颗都能用，凑齐才有质变。敌人通常只带自己那一种；玩家跨战斗收集。这是「独立原则 + 玩家更强」的交点。

可防的直伤 + 少量状态
    感染打击 3 伤 + 1 毒：一半能格挡，毒是税不是死刑。不要把压力全放在不可防那一侧。

让诅咒打得掉
    垃圾牌 0～1 费，或打出消耗。玩家可以花资源清，也可以吃惩罚省费。没有第三条路时（又贵又必须留着手），就是不友好。现行：孢子 1 费，打出消耗、留着手上毒后虚无。

## 动手前问自己

    玩家 50 血挨一次这个，这回合还能打吗
    敌人 90～180 血挨同样的，还有没有感觉
    这个效果占不占敌人的行动
    同化这颗之后，玩家用它是否比敌人用它更值（费用、抽牌、升级、连携）
    如果答案是「敌人更值」，换效果类型，不要写双模式

## 现行：疫孢菌母

    血量 90
    感染打击 3 伤 + 1 毒，挂在菌网根系上，同化拿得到
    菌网：对对手上毒时抽 1（每回合 3 次 / 2 级 5 次）；3 级锻感染打击为 0 费 2 毒。敌人抽牌目前空转，Boss 战不加毒压
    出牌在 `battleList`：常规四拍爆发→蔓延→感染或硬化×2；≤30% 改为双卡招（爆发+蔓延，随后三拍蔓延+硬化）。费用按 3 费上限排，没有把硬化打满三张同一回合
    剧毒心核仍是施加中毒 +1，没有每回合被动毒
    孢子 1 费：打出消耗清掉；留着手则回合结束 1 层中毒再虚无

中毒体系本身要重做（多种毒、连携、玩家侧输出更高 / 自伤更低）。在那之前，不要再给敌人加「每回合固定上毒」。
