# 卡牌引用系统

描述里点名一张牌，悬停出卡面、点击打开锻造对照。占位符还是 `{ "@": … }` 和 `{ "#": key }`，没有删。变的是器官正文不再手写「提供1张 `{ "@": 0 }`」，那句由引擎按 `cards` / 当前挂载生成，生成出来的仍然是 `{ "@": n }`。

组件：`DescribeText` → `CardRefText`（内部 `Popover`）
解析：`src/ui/hooks/express/describe.ts`、`src/ui/hooks/express/cardSegment.ts`

## 占位符

### `{ "@": 索引或实例ID }`

点名一张已经在牌组里、或器官即将提供的牌。数字是列表下标，字符串是运行时 `__id`。

器官正文的提供句里的 `{ "@": n }` 是 `composeOrganDescribe` 写进去的。升级里程碑锻牌糖（`forgeProvideDescribe`）也会自己写 `{ "@": n }`。其它描述要点名某张牌时，仍然自己写。

```typescript
describe: ["下回合这张", { "@": 0 }, "会耗尽"]   // 自己写，索引对应当前上下文的卡牌列表
```

### `{ "#": 卡牌key }`

按 key 造一张临时牌做预览，不进牌堆。事件、遗物「将会获得某某」用这个。

```typescript
describe: ["下回合获得1张", { "#": "original_card_00001" }]
```

### `{ organ: 器官key }`

按 key 预览一颗器官。事件选项「将会获得 / 失去某某器官」用这个（现行：接生、收藏家）。悬停出 `OrganRefText` → `OrganHoverContent`。胚胎要带发育轮数时加上 `evolutionRounds`。

```typescript
description: ["获得", { organ: "original_organ_00002" }]
description: (data) => ["获得", { organ: embryoOrganKey(data), evolutionRounds: data.evolutionRounds ?? 0 }]
```

### `{ relic: 遗物key }`

按 key 预览一件遗物。悬停出 `RelicRefText` → `RelicHoverContent`。

```typescript
description: ["获得", { relic: "event_relic_incubating_embryo" }]
```

### `{ text, fx }`

Describe 正文演出。`text` 是字，`fx` 是 `describeFx` 注册表里的特效 key（字符串或数组）。`beat` 是打字机（reveal），`shake` 是持续轻抖（motion），写在同一个 `fx` 里就能叠。`wait` 是上一段 beat 打完后再等几秒才开始（第一段从正文出现时算），不写当作 0。`char` 是 beat 每个字间隔秒数，不写当作 0.08。其它文本照常直接出现。关掉界面动画时一次全出、不抖。现行：杯之祭坛。

```typescript
{ text: "咔嚓", fx: "shake" }

{ text: "嚼……", fx: ["beat", "shake"], wait: 0.3, char: 0.1 }
{ text: "嚼……", fx: ["beat", "shake"], wait: 0.45 }
{ text: "嚼……", fx: ["beat", "shake"], wait: 0.6 }
```

不要再写 `{ shake: "咔嚓" }` / `{ beat: "嚼……", shake: true }`。怎么注册新特效见《动画实现场景手册》场景 16。

## 器官正文

只写 `cards`（或 `cardsByOwner`）。`DescribeText` 收到的就是器官自己的 `describe` 时，会先 `composeOrganDescribe`：

已装备    按当前挂载 `getCardsFromSource`（移植后给出的那颗这句消失，接到的那颗列出新挂上的牌）
未装备    按 `cards` / `cardsByOwner`（奖励、黑市预览）

```typescript
{
    label: "战斗之心",
    describe: ["最大生命 +2"],
    cards: ["original_card_00001"]
}
```

被动要分行，在 `describe` 里写 `"<br>"`。提供卡那一行不用写（现行：孢子囊）。

```typescript
describe: ["损坏时对所有敌人施加", { key: ["status", "break-poison"] }, "层", { $: "中毒" }]
cards: ["enemy_card_toxic_spore"]
```

多张卡：`cards` 写多把 key，介绍自动写成「提供N张A和B卡牌」（现行：女王大颚）。

获得器官时不再把索引改成实例 ID。运行时 `{ "@": 0 }` 是正常的，每次渲染按当时的挂载或配置去查。

锻牌那句「锻造提供的xx卡牌」仍认当初给出的牌（`card.provider`），不跟移植走。见器官实现场景手册场景 10。

## 渲染

不要自己遍历 segments 再手写 hover，交给 `DescribeText`：

```vue
<DescribeText :describe="organ.describe" :target="organ" bracket-cards />
```

`type === "card"` 交给 `CardRefText`，悬停懒解析并用 `Popover` 出卡面。这段文字里的 `$` 和 `extraGlossaries` 组成术语板。详见《浮层系统》。

`getDescribe` / `describe.ts` 不要值导入 `cardSegment.ts`。那会在加载阶段把 `Card`、`nowPlayer` 拉进 `Player` 的初始化，触发 `Cannot access 'Chara' before initialization`。描述里的卡名用 `getCardModifier` 和 `getLazyModule('cardList')` 拼字；完整卡面预览留给 `CardRefText`。见《常见错误排查手册》L1。

## Describe 类型

```typescript
export type Describe = (
    string                     // 恰好为 "<br>" 时是换行
    | { key: string[] }        // 访问属性
    | { $: string }            // 术语标记
    | { "@": string | number } // 卡牌实例引用（索引或 __id）
    | { "#": string }          // 卡牌 key 预览
    | { organ: string, evolutionRounds?: number }  // 器官 key 预览
    | { relic: string }        // 遗物 key 预览
    | { text: string, fx: string | string[], wait?: number, char?: number }
)[]
```

渲染后的片段：

```typescript
export type DescribeSegment = {
    text: string
    type: "plain" | "value" | "glossary" | "card" | "break" | "organ" | "relic" | "fx"
    cardRef?: string | number
    cardRefType?: "instance" | "key"
    organKey?: string
    evolutionRounds?: number
    relicKey?: string
    fxKeys?: string[]
    beatStart?: number
    beatChar?: number
}
```

数字 `@` 的 `cardRefType` 是 `"instance"`：有实体用实体（含锻造后的 `名字+`），没有再按 key 造预览。

## 查找顺序

`{ "@": n }`（数字）

    已装备：`getCardsFromSource(organ)[n]`
    找不到：`organ.cards[n]`，再退 `cardsByOwner.player[n]`
    奖励预览可加 `preferPlayerCards`，优先玩家版

`{ "@": "__id" }`（字符串）

    先在该器官当前挂载里找
    再搜玩家四个牌堆（手牌 / 抽牌 / 弃牌 / 消耗）

`{ "#": key }`

    `createCardFromKey` 造临时实例，不进牌堆，不影响局内状态

`{ organ: key }`

    从表里取名字，悬停时 `getOrganByKey` 造预览实例。`evolutionRounds` 写到预览器官的 status 上（现行：接生）

`{ relic: key }`

    从表里取名字，悬停时 `createRelic` 造预览实例

## 注意

`{ "@": n }` 运行时可以是索引。不要再在获得时改写 `organ.describe`。

挂载空了（牌被移植走、器官丢掉）时，提供句按当前挂载生成，不会再点名那张牌。其它描述里如果还手写着 `{ "@": n }` 而列表里没这张，卡名会显示成「[卡牌]」。

`{ "#": key }` 的临时牌只用于显示。
