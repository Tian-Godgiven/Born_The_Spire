# 卡牌引用系统

卡牌引用系统允许在describe中标记卡牌，使其可以在UI中hover显示完整的卡牌信息。

## 占位符格式

### {@:索引或ID} - 卡牌实例引用

用于点名一张已经存在或即将由器官提供的牌。器官正文里的「提供N张xx卡牌」不要手写，引擎按 `cards` / 当前挂载生成，里面的 `{ "@": n }` 也是生成的。

其它描述（升级里程碑锻牌糖、临时说明）仍可自己写 `{ "@": 0 }`，索引对应那份卡牌列表。

### {#:卡牌key} - 卡牌key预览

用于临时效果或预览，不引用实际实例。

```typescript
{
    describe:["下回合获得1张",{#:"original_card_00001"}]
}
```

## 工作流程

### 器官正文

只写 `cards`（或 `cardsByOwner`）。`DescribeText` 看到器官自身的 `describe` 时会调用 `composeOrganDescribe`：已装备按当前挂载 `getCardsFromSource`，未装备按配置。移植后给出的那颗不再显示提供句，接到的那颗会列出新挂上的牌。获得器官时不再改写 `describe`。

```typescript
{
    label: "战斗之心",
    describe: ["最大生命 +2"],
    cards: ["original_card_00001"]
}
```

### 渲染阶段

不要自己遍历 segments 再手写 hover，交给 `DescribeText`：

```vue
<DescribeText :describe="organ.describe" :target="organ" bracket-cards />
```

它内部解析结构化片段，把 `type === 'card'` 的交给 `CardRefText`，由后者悬停时懒解析卡牌并用 `Popover` 弹出卡面；这段文字里的 `$` 和调用方传入的 `extraGlossaries` 组成术语板。详见《文档/子系统/UI/浮层系统.md》。

`getDescribe` / `describe.ts` 不要值导入 `cardSegment.ts`。那会在模块加载阶段把 `Card`、`nowPlayer` 拉进 `Player` 的初始化，触发 `Cannot access 'Chara' before initialization`。描述里的卡名用 `getCardModifier` 和 `getLazyModule('cardList')` 拼字；完整卡面预览留给 `CardRefText`。见《常见错误排查手册》L1。

## Describe类型定义

```typescript
export type Describe = (
    string                     // 恰好为 "<br>" 时是换行
    | {key:string[]}           // 访问属性
    | {$:string}               // 术语标记
    | {@:string|number}        // 卡牌实例引用（ID或索引）
    | {#:string}               // 卡牌key预览
)[]
```

器官介绍里被动要分行时，在 `describe` 数组里写 `"<br>"`。提供卡那一行不用写：

```typescript
describe: ["损坏时对所有敌人施加 3 层", { $: "中毒" }]
cards: ["enemy_card_spore"]
```

## DescribeSegment类型

```typescript
export type DescribeSegment = {
    text: string
    type: 'plain' | 'value' | 'glossary' | 'card' | 'break'
    cardRef?: string | number          // 卡牌引用（ID、key或索引）
    cardRefType?: 'instance' | 'key'   // 引用类型
    // ...
}
```

## 使用场景

### 器官提供的卡牌

写 `cards`，不要在 describe 里手写提供句：

```typescript
{
    cards: ["original_card_00001"]
}
```

### 临时效果预览

使用 {#:key}，创建临时实例显示：

```typescript
{
    describe:["战斗开始时获得1张",{#:"original_card_00001"}]
}
```

### 多张卡牌

`cards` 写多把 key 即可，介绍自动写成「提供N张A和B卡牌」。

## 卡牌查找逻辑

### 实例引用 {@:id}

```typescript
// 从玩家牌堆中查找
function findCardById(cardId: string): Card | null {
    const cardModifier = getCardModifier(nowPlayer)
    const allCards = cardModifier.getAllCards()
    return allCards.find(card => card.__id === cardId) || null
}
```

### Key预览 {#:key}

```typescript
// 创建临时实例（cardSegment.ts）
async function createCardFromKey(cardKey: string): Promise<CardType | null> {
    const cardList = getLazyModule<any[]>('cardList')
    const cardData = cardList.find(c => c.key === cardKey)
    if (!cardData) return null
    const { createCard } = await import('@/core/factories')
    return await createCard(cardData)
}
```

## 注意事项

索引在运行时不应出现
  静态数据中的索引应该在器官获得时被替换为ID
  如果运行时遇到索引，会输出警告

卡牌失去时的处理
  当卡牌因事件失去时，describe中的引用会失效
  UI渲染时会找不到卡牌，显示为空

临时卡牌的生命周期
  使用 {#:key} 创建的临时卡牌仅用于显示
  不会添加到牌堆，不会影响游戏状态
