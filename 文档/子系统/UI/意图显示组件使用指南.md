# 意图显示组件使用指南

`IntentDisplay` 组件用于展示敌人下回合的行动意图。搭配 `Enemy.setIntent()` API 使用。

源文件：
    组件：`src/ui/components/display/IntentDisplay.vue`
    类型：`src/core/objects/system/Intent.ts`
    Enemy 侧 API：`src/core/objects/target/Enemy.ts`（`setIntent` / `updateIntent`）

## Props

```typescript
{
    intent?: Intent   // 意图对象，可选；不传或为 undefined 时组件不渲染任何内容
}
```

## Intent 类型

```typescript
type IntentPart = {
    type:  IntentType
    value?: number
    count?: number
}

type Intent = {
    type:        IntentType         // 首段类型（兼容旧读取）
    value?:      number             // 首段数值
    count?:      number             // 首段攻击次数（>1 时才展示 ×N）
    parts:       IntentPart[]       // 每张行动牌一段，多招并排显示
    actions:     Card[]             // 实际要执行的卡牌列表
    visibility?: IntentVisibility   // 可见性等级，默认 "card"
}
```

type IntentType =
    | "attack"    // 攻击
    | "defend"    // 防御
    | "buff"      // 增益
    | "debuff"    // 减益
    | "heal"      // 治疗
    | "escape"    // 逃跑
    | "special"   // 特殊
    | "unknown"   // 未知

type IntentVisibility =
    | "hidden"    // 完全不可见（显示 "?"）
    | "type"      // 只显示图标，不显示数值
    | "range"     // 显示估算范围（±20%）
    | "exact"     // 显示精确数值
    | "card"      // 精确数值 + 悬停展示卡牌详情（默认）
```

**注意**：只有 `attack` `defend` `buff` `debuff` `special` `unknown` 有专用图标（`⚔️🛡️↑↓✨?`）与颜色边框；`heal` `escape` 会走 `unknown` 视觉分支。若加新意图类型，需要同时在组件的 `intentIcon` `intentLabel` `intentDescription` computed 和 SCSS 的 `.intent-<type>` 中扩展。

## Enemy.setIntent 用法

```typescript
async setIntent(
    cards:      Card[],
    visibility: IntentVisibility = "card",
    intentType?: IntentType | (IntentType | undefined)[],  // 单类型或与 cards 对齐的数组；不传则每张按效果推导
    target?:    Player                // 用于模拟 target 端 buff（易伤/减伤）
): Promise<void>
```

**默认可见性是 "card" 而非 "exact"**。默认情况下敌人的具体行动卡对玩家是可见的。若要隐藏细节，需显式传更弱的 visibility。

内部流程：`setIntent` → `cardsToIntent(cards, this, visibility, intentType, target)` → 每张牌生成一段 `parts`（类型+数值），组件并排画图标。

多张行动牌（充能+打击）会看到两个意图徽章。声明单个 intent 字符串会套在每一张上；要混搭就写数组或不填。

意图 buff 影响自动生效：更新 buff（如玩家给自己上易伤）后调用 `enemy.refreshIntent()` 重算即可，不要用 `updateIntent()`（那会重新选招并推进循环指针）。

## 基础使用

单个敌人卡片展示意图：

```vue
<template>
<div class="enemy-card">
    <div class="enemy-name">{{ enemy.label }}</div>
    <div class="enemy-hp">
        {{ enemy.current.health.value }} / {{ enemy.status["max-health"].value }}
    </div>
    <IntentDisplay :intent="enemy.intent" />
</div>
</template>

<script setup lang="ts">
import IntentDisplay from "@/ui/components/display/IntentDisplay.vue"
import type { Enemy } from "@/core/objects/target/Enemy"

defineProps<{ enemy: Enemy }>()
</script>
```

`enemy.intent` 是 reactive 属性，变化自动重新渲染。

## 意图改变动画

组件内置了 `.intent-changing` class 的 keyframes 动画（600ms），需外部触发 class 才生效：

```vue
<script setup lang="ts">
import { ref, watch } from "vue"

const props = defineProps<{ enemy: Enemy }>()
const isChanging = ref(false)

watch(() => props.enemy.intent, (newVal, oldVal) => {
    if (newVal && oldVal && newVal !== oldVal) {
        isChanging.value = true
        setTimeout(() => { isChanging.value = false }, 600)
    }
})
</script>

<template>
<IntentDisplay
    :intent="enemy.intent"
    :class="{ 'intent-changing': isChanging }"
/>
</template>
```

## 可见性等级效果对照

```
hidden   显示"?"，不显示数值和图标以外的信息
type     只显示类型图标，不显示数值
range    显示估算范围，取真实值的 80%-120% 例："8-12"
exact    显示精确数值 例："10"
card     同 exact 显示数值，悬停 tooltip 内展示 <Card> 组件列表
```

设置示例：

```typescript
await enemy.setIntent(cards, "hidden")      // 屏蔽全部信息
await enemy.setIntent(cards, "type")        // 只知类型不知量
await enemy.setIntent(cards, "range")       // 大致范围
await enemy.setIntent(cards, "exact")       // 精确数值
await enemy.setIntent(cards)                // 默认 "card"，可精确+看牌
```

## 颜色主题

组件内建 6 种类型的边框色 + 图标色（SCSS `.intent-<type>` 块）：

```
attack   #d32f2f  红
defend   #1976d2  蓝
buff     #388e3c  绿
debuff   #f57c00  橙
special  #7b1fa2  紫
unknown  #616161  灰
```

注意：`Intent.ts` 中 `intentTypeMap` 也带 `color` 字段，但目前**与组件 SCSS 定义的颜色不一致**（`intentTypeMap` 使用 `#ff4444` 系亮色）。组件实际渲染只用 SCSS 那套颜色，`intentTypeMap.color` 目前无消费者。如果 UI 要走"配置化颜色"路线，二者需先对齐。

## 自定义样式

因组件用 scoped 样式，外部覆盖需 `:deep()`：

```vue
<style scoped>
.enemy-card :deep(.intent-main) {
    padding: 8px 12px;
    min-width: 60px;

    .intent-icon { font-size: 24px; }
    .intent-value { font-size: 18px; }
}
</style>
```

## 悬停 tooltip

`intent-tooltip` 由 `.intent-display:hover` 触发显示：

```
visibility = "card"    展示 <Card> 组件列表（可看具体卡牌）
其他                    展示文本描述 "造成 N 点伤害" / "获得 N 点格挡" 等
count > 1              追加 "攻击 N 次"
非 exact/card 模式      追加提示文字（"数值为估算范围" 等）
```
