# 选择目标系统

玩家使用卡牌/药水/遗物时，需要通过 UI 选择目标。该系统由三部分组成：

    选择源 ChooseSource 组件：能作为发起选择的容器（卡牌/药水槽等）
    选择目标注册 targetManager：单例，管理场上所有 target 的选择状态
    选择流程控制 chooseTarget：解析 targetType、监听点击、驱动状态机

源文件：
    `src/ui/components/interaction/chooseTarget/ChooseSource.vue`
    `src/ui/interaction/target/targetManager.ts`
    `src/ui/interaction/target/chooseTarget.ts`
    `src/ui/hooks/interaction/handCardAim.ts`  手牌按住瞄准 / 松手打出

## 选择源 ChooseSource

Vue 组件，包装任何可作为选择起点的元素（当前使用者：`HandCard.vue` / `Potion.vue`）。

内部三态（互斥），控制视觉反馈：

```
"none"      默认
"hovering"  鼠标悬停（无其他选择在进行时）
"choosing"  已作为源发起选择
```

`hovering` 与 `choosing` 都放大到 1.2 倍（`.chooseSource.hovering, .chooseSource.choosing { transform: scale(1.2) }`）。手牌始终传 `disableScale`，悬停只放大到 1.08，瞄准时改由卡面自己上浮/倾斜。

Props：

```typescript
{
    onSuccess: (targets: Target[]) => void   // 必需
    onHover?:  (target?: Target) => void
    onStop?:   () => void
    disableScale?: boolean                   // 关掉 ChooseSource 自带的 1.2 倍放大
}
```

Expose：

```typescript
startChoose({
    targetType: TargetType,
    source?: Entity,
    ifShowConnectLine?: boolean
})
```

使用方通过 template ref 调用 `startChoose`。药水仍是点击后 `startChoose`。手牌走按住瞄准，见下方「手牌按住瞄准」。

## 目标管理 targetManager

单例，维护 `targets` 和 `factions` 两个 reactive Map。

每个 target 挂一个 `TargetChooseState`：

```typescript
interface TargetChooseState {
    isSelectable: boolean   // 可选：会为其生成一个虚线选择框
    isHovered:    boolean   // 悬停：选择框高亮
    isSelected:   boolean   // 已选中：选择框固定
}
```

阵营侧同样挂 `TargetChooseState`，全选行为时框住整个阵营容器。内置三阵营：`player` / `enemy` / `all`。

关键 API：

```typescript
targetManager.addTarget(target)                    // 进入战斗时注册
targetManager.removeTarget(target)                 // 离场时注销
targetManager.setSelectableTargets(targets[])      // 批量置为可选（会清空其他 target 的选择状态）
targetManager.setTargetState(target, state, val)   // 单独改某 target 的一个状态位
targetManager.setFactionState(key, state, val)     // 改整个阵营容器的状态位
targetManager.stopSelection()                      // 清空所有选择状态并返回本次已选目标
targetManager.getSelectedEntities()                // 收集已选目标（含"选中阵营"展开到所有成员）
```

`setSelectableTargets` 有前置校验：调用时必须 `choosingTarget.value === true`，否则抛错。

## 选择流程控制 chooseTarget

全局响应式状态：

```typescript
choosingTarget: Ref<boolean>              // 当前是否处于选择状态
nowChooseAction: Ref<{
    chosenTargets: Target[],
    chooseRule: ChooseRule | null,
    onSuccess / onStop / onHover: 回调,
    removeListener: () => void
}>
```

### ChooseOption

```typescript
type ChooseOption = {
    targetType: TargetType             // 选择规则（详见 TargetType 系统）
    source?: Entity                    // 使用者，用于判断 opponent 阵营
    ifShowConnectLine?: boolean        // 是否显示连接线，默认 true
    onHover?:   (target: Target) => void
    onSuccess:  (targets: Target[]) => void
    onStop?:    (targets: Target[]) => void
}
```

### ChooseRule 与规则解析

`resolveTargetTypeRules(targetType, source)` 把 `targetType` 编译为运行时规则：

```typescript
type ChooseRule = {
    specificTargets: Target[] | null   // 优先级 1：指定 key（如 "self"）时解析出的固定目标集
    faction:         "enemy" | "player" | "all"   // 阵营（opponent 会被 source 阵营翻转）
    chooseAll:       boolean           // targetType.number === "all"
    noNeedChoose:    boolean           // 无需用户点击，左键即自动完成
    noValidTargets:  boolean           // 场上没有任何可选目标
    needChooseNum:   number            // 还需要点击几次
}
```

优先级：`specificTargets` > `chooseAll` > `faction+needChooseNum`。

`noNeedChoose` 触发条件（`checkChooseNum`）：

```
targetType.number === "all"          → true
targetType.faction === "all"         → true
targetType.key 存在且 specificTargets 只有 1 项  → true（如 "self"）
其他                                  → false
```

### 完整流程

```
使用方 → startChoose(option)
    ↓
initStartChooseTarget()：清空线条 + choosingTarget = true
    ↓
resolveTargetTypeRules(targetType, source) → ChooseRule
    ↓
setChooseAbleBlock(rule)：
    有 specificTargets     → setSelectableTargets(specificTargets)
    chooseAll              → setFactionState(faction, "isSelectable", true)
    其他                    → setSelectableTargets(该阵营全体)
    ↓
showConnectLine(startPosition)：绘制从选择源到鼠标的连接线
    ↓
startListenClick()：全局监听 click / contextmenu
    ↓（等待用户交互）
用户左键单个可选目标   → chooseATarget(target) → chosenTargets.push
用户左键阵营框         → chooseAFaction(targets[]) → chosenTargets.push(...)
用户左键（noNeedChoose）→ autoChooseTarget()
用户右键 / 空白左键     → endChooseTarget() → onStop
    ↓
chosenTargets.length === needChooseNum ？
    是 → successChooseTarget() → onSuccess(chosenTargets)
    否 → staticConnectLine() 固定当前线条，继续等待下一次选择
    ↓
endChooseTarget()：清听 + stopSelection + clearConnectLine + 重置 nowChooseAction
```

同一时刻仅允许一个选择源。重复调用 `startChooseTarget` 会覆盖前一次。

## 手牌打出

战斗手牌两套都保留。实现：`HandCard.vue` + `src/ui/hooks/interaction/handCardAim.ts`。

点击
    在卡上按下再松开、且没有拖出武装距离 → 进入选中（上浮 + 发光 + `startChoose`），再点目标打出。选中后仍按指针左右倾斜。
    右键取消选中。点空白不会取消。
    `pointerdown` 会 `preventDefault`，所以点选是在 `pointerup` 里启动的，不是等浏览器 `click`。

按住瞄准
    指针按下：能量够、可打出、未禁用、且不在事件选牌模式 → 进入瞄准。卡面上浮约 22px，左右倾斜夹在 ±10°，跟上指针用约 0.2s 过渡。`pointer capture`，指针离开卡面也不丢。
    离卡心 ≥ 90px：武装（阴影发光）。此时才 `startChoose`，并画出选择线。
    指针进到合法目标上：`syncAimHover` 把选择框从虚线改成实线。capture 期间目标收不到 mouseenter，必须靠落点同步。
    移回 90px 内：光灭，取消当前拖出选择。松手则改走上面的点击点选。
    武装后松手：
        落在合法目标 / 阵营框 → `chooseATarget` / `chooseAFaction`
        自身 / 全体（`noNeedChoose`）且松在手牌区外 → `autoChooseTarget`
        要选多个目标：第一发仍用这次松手，剩下的沿用原来的点击
    取消拖出：武装后松在空白、或松在手牌区（`[data-hand-pile]`）
    打出确认后仍走现有飞牌（`beginCardPlay`）。瞄准过程不播飞牌。
    松手后吞掉紧随的 `click`，避免结束回合 / 目标被点两次。
    能量不足时不进瞄准也不进点选，但按下仍 `preventDefault`。Running 页 `user-select: none`，避免拖牌把整页刷蓝。开发者日志仍可划选。

不进入这两套：能量不足、`cannot-play`、禁用、事件手牌选择器。选择器仍用点击勾选。

落点靠 DOM 标记，不要手算坐标：

    `[data-hand-pile]` 手牌区（松在这里一律取消）
    `[data-battle-target-id]` 单个目标（`Target.vue`）
    `[data-battle-faction]` 阵营容器（`Faction.vue` / `AllFactions.vue`）

## Promise 风格封装

`chooseTarget` 提供 `async/await` 友好的替代入口，供不方便传回调的场景使用：

```typescript
import { chooseTarget } from "@/ui/interaction/target/chooseTarget"

const targets = await chooseTarget({
    targetType: { faction: "enemy", number: 1 },
    source: player
})

if (targets === null) {
    // 用户取消选择
    return
}
// targets: Target[]
```

`onStop` 无已选目标时 resolve `null`，有则 resolve 数组；`onSuccess` 一律 resolve 数组。
