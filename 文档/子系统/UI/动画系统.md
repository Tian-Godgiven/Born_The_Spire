# 动画系统

全局动画基础设施，基于 GSAP，统一管理所有 UI 动画的注册、播放、冲突和回调。

## 基本信息

位置：`src/ui/animation/`
底层：GSAP（项目已有依赖）
入口：`src/ui/animation/index.ts`

### 文件结构

```
src/ui/animation/
  index.ts                    统一导出
  types.ts                    类型定义
  AnimationManager.ts         全局管理器单例
  useAnimation.ts             组件内 composable
  presets.ts                  内置预设动画
  categories.ts               动画类别注册表（设置面板按类别开关）
  components/HitTextItem.vue  受击跳字条目（append 模式的 appendComponent）
```

## 核心概念

### 效果模式（mode）

overlay
  保持原 DOM 不变，叠加视觉效果
  例：闪烁、发光、变色、震动

replace
  临时替换 DOM 内容播放动画
  例：死亡演出、变身动画
  通过 replaceComponent 指定替换组件

append
  在 DOM 旁边/上方添加额外元素
  例：跳字、粒子效果
  通过 appendComponent 指定附加组件
  与另外两种模式的关键差别：AnimationManager 完全不碰 DOM，视觉全部由 appendComponent 自己实现，
  timeline 只是"多久之后把这一项摘掉"的计时器，时长写在顶层 duration 字段（秒）
  append 不走 channel 互斥，多次播放会多份实例并存（连击跳字就靠这个）
  不要给 append 写 animate / build——它们的目标是宿主元素，会让角色本体飘走

### Channel 系统

同 channel 的动画互斥，不同 channel 并行
  channel: "color" → 闪红和闪绿互斥
  channel: "position" → 震动和后退互斥
  不同 channel 之间自由叠加

### 优先级（priority）

同 channel 内，高优先级动画可以打断低优先级
  默认 priority: 0
  死亡动画 priority: 999，打断一切

### 重复策略（repeat）

同 key 动画重复触发时的行为
  restart：重新开始（默认）
  ignore：忽略新触发
  queue：排队等当前播完

### 可打断（interruptible）

默认 true，允许被同 channel 更高优先级动画打断
设为 false 时，其他动画只能排队等待

## 动画定义

### 声明式简写（简单动画）

```typescript
{
  key: "death_fadeout",
  mode: "overlay",
  channel: "death",
  priority: 999,
  animate: {
    to: { opacity: 0 },
    duration: 0.6,
    ease: "power1.in"
  }
}
```

animate 字段支持：
  from + to：fromTo 动画
  仅 from：from 动画
  仅 to：to 动画
  duration：持续时间（秒），默认 0.5
  ease：缓动函数，默认 "power1.inOut"

### build 函数（复杂动画）

```typescript
{
  key: "hit_shake",
  mode: "overlay",
  channel: "position",
  build: (el) => {
    return gsap.timeline({ paused: true })
      .to(el, { x: -6, duration: 0.04 })
      .to(el, { x: 6, duration: 0.04 })
      .to(el, { x: -4, duration: 0.04 })
      .to(el, { x: 4, duration: 0.04 })
      .to(el, { x: 0, duration: 0.04 })
  }
}
```

build 接收 DOM 元素和可选的 params 参数，返回 paused 的 GSAP Timeline
build 和 animate 二选一，build 优先

### 时间轴回调

在动画定义中声明回调节点，调用方决定具体行为：

```typescript
// 定义
{
  key: "boss_death",
  mode: "overlay",
  channel: "death",
  build: (el) => { /* ... */ },
  callbacks: [
    { at: 300, action: "dropLoot" },
    { at: 500, action: "playSound" }
  ]
}

// 使用
await play("boss_death", {
  onAction: (actionKey, elapsed) => {
    if (actionKey === "dropLoot") spawnLoot()
    if (actionKey === "playSound") playDeathSound()
  }
})
```

at：触发时机（毫秒）
action：回调标识 key

## 使用方式

### 组件内使用（useAnimation）

```vue
<template>
  <div ref="animRef">
    <!-- replace 模式组件 -->
    <component v-if="replaceComponent" :is="replaceComponent" />
    <slot v-else />
    <!-- append 模式附加项 -->
    <component v-for="item in appendItems" :key="item.id"
      :is="item.component" v-bind="item.props" />
  </div>
</template>

<script setup>
import { useAnimation } from "@/ui/animation"

const { animRef, play, cancel, cancelAll, isAnimating, replaceComponent, appendItems } = useAnimation("my_element_id")

// 播放动画，返回 handle
const handle = await play("hit_flash")

// 等待动画完成
await handle.promise

// 带回调播放
await play("boss_death", {
  params: { intensity: 2 },
  onAction: (key, ms) => { /* ... */ },
  onStart: () => { /* ... */ },
  onEnd: () => { /* ... */ },
  onCancel: () => { /* ... */ }
})

// 取消动画
cancel("color")      // 取消指定 channel
cancelAll()           // 取消所有（含队列）
```

useAnimation 返回值：
  animRef：绑定到 DOM 元素的 template ref
  play(animKey, options?)：播放动画，返回 Promise<AnimationHandle>
  cancel(channel?)：取消指定 channel 或所有 channel
  cancelAll()：取消所有动画和队列
  isAnimating：是否有活跃动画（computed）
  replaceComponent：replace 模式当前组件（computed）
  appendItems：append 模式附加项列表（computed）

### AnimationHandle

```typescript
const handle = await play("death_fadeout")

handle.key          // 动画 key
handle.channel      // channel
handle.promise      // Promise<void>，动画结束时 resolve
handle.cancel()     // 主动取消
handle.isPlaying()  // 是否正在播放
```

### 直接使用 AnimationManager

```typescript
import { animationManager } from "@/ui/animation"

// 注册
animationManager.register({ key: "custom", mode: "overlay", /* ... */ })

// 播放（需要先 bind 元素）
animationManager.bind("enemy_1", domElement)
await animationManager.play("enemy_1", "hit_flash")

// 全局取消（场景切换时）
animationManager.cancelGlobal()
```

## 注册动画

### 注册预设动画

在 main.ts 中自动注册：

```typescript
import("@/ui/animation").then(({ registerPresetAnimations }) => {
  registerPresetAnimations()
})
```

### Mod 注册自定义动画

```typescript
import { animationManager, registerAnimationCategory } from "@/ui/animation"

animationManager.register({
  key: "boss_explode",
  category: "death",        // 挂到内置类别，玩家关掉「死亡演出」时它也一起关
  mode: "replace",
  channel: "death",
  priority: 999,
  interruptible: false,
  replaceComponent: BossExplodeAnimation,
  callbacks: [
    { at: 500, action: "screenShake" },
    { at: 1000, action: "dropReward" }
  ]
})

// 想要设置面板里单独一行开关，就注册自己的类别
registerAnimationCategory({
  key: "myMod_ritual",
  label: "仪式特效",
  describe: "献祭与召唤时的全屏演出"
})
```

`category` 不填的话动画不受任何开关管辖、永远播放。给 Mod 动画填上类别是基本礼貌。

## 内置预设

death_fadeout
  渐隐，channel: death，priority: 999，不可打断
  用于实体死亡

hit_flash
  白闪，channel: color
  用于受击反馈

hit_shake
  左右震动，channel: position
  用于受击反馈

hit_text
  受击跳字，mode: append，duration: 1.8
  视觉在 HitTextItem.vue 内部，由 HitText.vue 通过触发器驱动

heal_glow
  绿光，channel: color
  用于治疗反馈

fade_in / fade_out
  淡入/淡出，channel: visibility

scale_in
  缩放弹入，channel: visibility

pulse
  脉冲放大缩小，channel: emphasis

## 全局动画设置

玩家可以在设置面板里调速度、按类别关演出，或者一键跳过全部动画。闸门开在 `AnimationManager.play` 一处，
所有走动画系统的效果自动受控——这也是新增动画必须走动画系统、不要直接写 CSS 动画的原因。

设置字段（`src/core/persistence/settings.ts`）

```
animationSpeed        速度倍率，档位见 ANIMATION_SPEED_OPTIONS（0.5x ~ 3x）
skipAnimation         跳过全部动画的总开关，压过所有分类开关
animationCategories   分类开关，Record<类别key, boolean>，只记玩家主动关掉的项
```

速度的实现分两条路径

```
overlay / replace   timeline.timeScale(倍率)，gsap 直接控制
append              组件内是 CSS 动画，gsap 管不到，所以 props 里下发的 duration 单独除以倍率
```

跳过与关类别走同一条空转路径（`playSkipped`）

```
不建时间轴、不碰 DOM、不塞 appendItems
但 onStart / callbacks / onEnd 照常触发，promise 照常 resolve
```

promise 必须 resolve 是硬约束：死亡演出、卡牌展示都在 `await handle.promise`，
不 resolve 会让流程永久卡死。由此推出一条设计约束：**不要把游戏逻辑写在动画里**，
玩家关掉动画后只有视觉消失，流程必须照走。

分类开关的判定是 `!== false`，存档只记被关掉的项，所以新增类别不会因旧存档缺 key 而默认关闭。

## 动画类别

类别做成注册表（`src/ui/animation/categories.ts`），Mod 既能把动画挂到内置类别，
也能 `registerAnimationCategory` 注册新类别，设置面板遍历注册表自动多出一行。

```
hit       受击表现    hit_flash / hit_shake
hitText   伤害跳字    hit_text
heal      治疗表现    heal_glow
death     死亡演出    death_fadeout
card      卡牌演出    card_appear / card_ascend_fadeout / card_duplicate_fadeout
ui        界面通用    fade_in / fade_out / scale_in / pulse
```

动画定义里不填 `category` 就不受任何开关管辖，永远播放。

## 受击表现接线

受击的三样表现都由触发器驱动，挂在 UI 组件里，不改任何游戏状态。

```
CharaAnimator.vue   after/take/damage → hit_flash + hit_shake
HitText.vue         after/take/damage → hit_text 跳字（伤害 / 格挡）
                    after/take/heal   → hit_text 跳字（治疗）
```

跳字层刻意挂在 `CharaAnimator` **外面**：死亡演出会把动画容器整个淡出并 `visibility: hidden`，
放在里面的话致命一击的数字会跟着一起消失。

数值取的是 health / armor 的前后快照差值，不是 `effect.params.value`——这样减伤、护甲吸收、
生命上限截断全都自动算进去。伤害快照挂 `on`、`TriggerLevel.HIGH`，压过护甲吸收的 `priority: 100`
（触发器按 level 降序执行），否则拿到的 armor 已经是扣完的值，算不出格挡量。

完整说明见 `文档/开发指南/场景手册/触发器实现场景手册.md` 场景 10。

## CharaAnimator 组件

位置：`src/ui/components/object/Target/Chara/components/CharaAnimator.vue`

基于动画系统的角色动画包装组件，自动监听 isAlive 播放死亡动画。

```vue
<CharaAnimator ref="animator" :target="enemy" death-animation="boss_explode">
  <div>角色内容</div>
</CharaAnimator>
```

Props：
  target（Chara）：角色实体
  deathAnimation（string）：死亡动画 key，默认 "death_fadeout"

暴露：
  isDying（ref<boolean>）：是否正在播放死亡动画
  isDead（ref<boolean>）：是否已死亡（动画播完）
  play：转发 useAnimation 的 play 方法

死亡后使用 visibility: hidden 保留占位，不影响其他元素布局。
