# 效果预览系统

意图数字和卡面伤害用同一套折叠，**不是**假打一遍战斗。

问的是：这条效果的 `params.value` 在 `before` / `on` 里那些**确定改数字**的效果过完之后是多少。

不创建结算用的事务，不跑 `after`，不扣层、不掷骰、不吸收护甲。

## 会进折叠的

效果 key 在 `PREVIEW_PARAM_MODIFIER_KEYS` 里，并且 reaction 的 `targetType` 是 `triggerEffect`：

    `modifyDamageValue` — 力量
    `modifyDamageByPercent` — 易伤、虚弱、飞飘/飞行减半
    `reduceDamageValue`
    `modifyArmorValue` — 意图上的格挡数字

触发器还要是 `when: "before"` 或 `when: "on"`，挂在攻击者 `make` / 媒介 `via` / 受击者 `take` 上。先折 before，再折 on，和真结算同一顺序。

`attack` 和 `damage` 都会扣血，但是两件不同的事。打人写 `attack`（飞飘、飞行、力量听这个）。中毒等非挨打写 `damage`。预览按这条效果自己的 key 去找触发器，所以中毒不会吃到飞行减半。

## 不进折叠的

    `after`（事后响应，改不了这条效果的数字）
    过期隔板掷骰（随机，还记损耗）
    飞飘/飞行扣层、薄翅扣层
    护甲吸收（`on` 上的机制回调，没有挂 `preview`）
    力场护盾把伤害置零（`nullifyDamageValue` 没进白名单）

这些只在真结算里发生。意图数字是减半后的攻击力，不含护甲。

## 文件

    `src/core/objects/system/effect/previewEffect.ts` — 折叠入口 `previewEffect`
    `src/core/objects/system/effect/previewApplicator.ts` — 声明式触发器挂上 `preview`
    `src/core/objects/system/Intent.ts` — 意图数字
    `src/core/utils/effectPreview.ts` — 卡面 `previewCardEffects`
    `src/ui/components/object/Card.vue` — 卡面读预览值

## API

```typescript
import { previewEffect } from "@/core/objects/system/effect/previewEffect"
import { previewCardEffects } from "@/core/utils/effectPreview"

const folded = previewEffect(
    { key: "attack", params: { value: 8 } },
    enemy,
    card,
    player
)
// folded.params.value 已含力量 / 易伤 / 飞行减半

const cardNums = previewCardEffects(card, nowPlayer, enemy)
// { attack: 10, damage: 10 }
```

没有传入受击目标时，只折攻击者自己的 before / on make（力量、虚弱），不会把玩家飞行折进自己的卡面。

## 给内容作者

要让某个加伤/减伤出现在意图和卡面上：用 `before` 或 `on` + `targetType: "triggerEffect"` + 上面那几个 modify* key。
飞飘/飞行减半挂 `before`，预览会折进去。

不要把掷骰、扣层写进同一个 EffectFunc 再指望预览自动跳过。预览根本不会调用那个函数。

`effectMap` 上的 `preview:` 字段是旧卡面预览留下的，折叠不再读它。
