# 布局适配

PC 和横屏手机共用同一套 DOM 和排位规则，数字分成两套 CSS 变量。不要为手机另写一套页面组件。

源文件：
    判定：`src/ui/hooks/global/layoutMode.ts`
    PC 变量：`src/ui/styles/layout/pc.scss`
    手机变量：`src/ui/styles/layout/mobile.scss`

`html[data-layout="pc"|"mobile"]` 由 `initLayoutMode()` 写入。粗指针（或无悬停）且短边 ≤ 900、并且已经横屏，才视为手机。竖屏一律走 PC 布局，不要盖「请横屏游玩」。

Android 全屏：点主菜单或选器官页的「开始游戏」时同步调 `requestGameFullscreen()`（`layoutMode.ts`）。必须写在 click 里、任何 `await` 之前，否则浏览器会丢掉用户手势直接拒绝。已经全屏、不是手机、或不支持（iPhone Safari）就当没发生。iOS 加到主屏幕先不做。

组件里写 `var(--layout-hand-height)` 这类变量，不要再写死战斗底栏的 px。间距 `gap` 用 `--layout-gap-lg` / `--layout-gap-md` / `--layout-gap-sm`，不要在页面里写死 `gap: 40px`。新的布局尺寸加进两份 scss 各一条，名字必须相同。

选初始器官的格子是方块。手机端 `--layout-organ-cols` × `--layout-organ-visible-rows`（现在 5×3）露出三排，多的在格子里滚。底栏走文档流，不要绝对定位压住网格。

手牌重叠宽度在 `HandPile.vue` 里跟 `layoutMode` 读同一套卡宽，因为那段是 JS 算的。数字必须和 `--layout-card-width` 一致（现在 PC 130、手机 112）。卡面标题 / 正文 / 词条走 `--layout-card-title-size` / `--layout-card-body-size` / `--layout-card-entry-size`（手机正文 14px）。

地图底部提示 `.map-footer` 手机端隐藏，标题栏已经够用。

战斗角色用 `--layout-chara-width` / `--layout-chara-height`（手机约 180×230）。阵营区只扣手牌露出条 `--layout-hand-height`（约 22vh），不要按整张卡高度去挤角色。手机角色额外 `translateY(-22px)` 略抬高，离开手牌露出条。

手机手牌往下沉 `--layout-hand-sink`，平时只露出顶部；悬停 / 点按抬到 `translateY(0)` 看整卡。手牌重叠在 `HandPile.vue` 里手机固定更紧（负间距），因为看牌靠抬起。

能量在手牌露出条上方左侧，两行（「能量」/「3/3」）。结束回合在右侧同一高度。抽牌堆、弃牌堆贴左右下角，消耗堆叠在弃牌堆上方。

能量、抽牌堆、弃牌堆、消耗堆不要写成死尺寸方块。`min-width/min-height` 用 `--layout-pile-size` / `--layout-energy-size`，实际宽高 `max-content` + `white-space: nowrap`，中文标签才不会折行。手机这两项 min 为 0。

顶栏 `--layout-top-bar-height` 只含名字/生命/按钮那一行。遗物条 `.relics-bar` 仍是 `position: absolute` 挂在顶栏下方，不要收进顶栏 flex 里占高度。手机遗物字 14px、内边距略加大。右上角地图/卡组/遗物/设置/返回用 `.ability` 的 `--layout-gap-sm`，不要挤成一串。按钮走 `Button.vue`：浅灰脸、切角、1px 上浅下深（`#f3f3f3` / `#9a9a9a`）做出轻微突起。外切 6px、黑边 2px、内切 4px，斜边才均匀；不要两层都写同一个切角，也不要用阴影。成交钮加 `invert`（黑脸白字）；房间操作尺寸加 `large`，padding / 字号走 `--layout-store-buy-*`。

离开按钮（水池仍用 `LeaveButton`）贴房间右下角，用 `--layout-leave-*`，不要 `fixed` + `top: 75%`。黑市离开、购买、出售都走 `Button.vue` 的 `large`，同一行 `position: fixed` 贴视口右下角，滚动货架时仍在；购买/出售在左（`invert`）、离开在右。

黑市货架 padding / 栏间距 / 商品间距走 `--layout-store-pad` / `--layout-store-gap` / `--layout-store-item-gap`（手机 8px 10px / 8px / 6px），不要在页面里写死 `1.5rem`、`20px`。标题栏手机 padding 为 `10px 12px 10px`。购买 / 出售分页切换。点选商品出详情，右下角弹出购买或出售钮才成交。卡牌是卡面本身，不再套一层说明。金币走顶栏。

选择器官弹窗 `.organ-reward-modal` 手机拉到约 94vw，单块器官 `--layout-organ-popup-width` 收窄，尽量一行放下三个。

黑市左侧不再放「持有 / 出售」。器官货牌宽度固定约 20%（一行五件，扣掉 `--layout-store-item-gap`），不要 `flex: 1` 把单件拉满。名 / 线 / 效果 / 价格；五件横排。`.store-panel` / `.sell-panel` 不要 `flex: 1; min-height: 0`，高度跟内容走，否则整页以为刚好一屏、竖滑起不来。货架 `max-width: 1200px` 居中。整页 `overflow-x: hidden`，不要整店左右滑。第二栏 `.store-second` 不要横滑、子项不要 `flex-shrink: 0`。卡牌行自己 `overflow-x: auto`。遗物和药水占剩余宽度，货牌 `flex: 1 1 0` 均分，不要固定 min/max 宽。稀有度走 `getRarityLabel`。出售页上方是进店抽定的最多 3 件收购，下方生命和物质两块。

战利品主弹窗 `.reward-modal` 用 `--layout-reward-*`。PC 仍是 600–800 宽、40px 内边距；手机上限 `min(540px, 72vw)`，最小高度约 56%，列表超出滚动。行插件和占住一份见 `文档/子系统/UI/战利品界面.md`。

其它运行中弹窗（选器官 / 选遗物 / 选牌、卡组、设置、失败、吞噬确认等）共用 `--layout-dialog-max-width` / `--layout-dialog-pad`，由 `mobile.scss` 覆盖，不另写一套组件。

水池选项走 `ChoiceContainer`。emoji 用 `--layout-choice-icon-size`（PC 3rem，手机 1.5rem），选项名 `--layout-choice-name-size`，说明 `--layout-choice-desc-size`。不要在组件里写死 `3rem`。

无常之神赌桌（`GodOfChanceTable`）铺满事件区。骰盘 `--layout-chance-board` / `--layout-chance-die`，右侧选项 `flex-shrink: 0` 钉在底下，不要用 500px 方块把「转身离开」裁掉。
