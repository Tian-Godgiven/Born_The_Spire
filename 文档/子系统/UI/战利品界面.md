# 战利品界面

战斗结束、事件发奖、宝箱打开，都走同一套领取页：`RewardModal`。它只负责列出奖励、领取、锁定、前进。某一行要多画标记或按钮、要占住不让领，用下面的接口，不要改 `RewardModal`。

组件：`src/ui/components/interaction/RewardModal.vue`
打开：`showRewards` / `grantLoot`（`src/ui/hooks/interaction/rewardDisplay.ts`）

弹窗从顶栏下沿开始，不要盖住生命/药水。尺寸变量见 `文档/子系统/UI/布局适配.md`。里面的遗物名、器官介绍仍用 `Popover`，见 `文档/子系统/UI/浮层系统.md`。

## 一行上有什么

每行默认：图标、标题、领取（或查看选择）。已领显示「已领取」，互斥锁定显示「已锁定」。

`Reward.blockClaim(label)` 占住这份：不画领取，右侧显示 `label`。`clearClaimBlock()` 取消。`isClaimBlocked()` 为真时 `requireAll` 也算可以前进。

```typescript
markedReward.blockClaim("小兽叼走了")
```

不要在 RewardModal 里为某个遗物写 `v-if`。占住是奖励自己的状态。

## 行插件

`rewardRowAddonRegistry` 给每一行挂组件。说明区、按钮区各渲染一次，用 `area` 区分。

```typescript
import { markRaw } from "vue"
import { rewardRowAddonRegistry } from "@/static/registry/rewardRowAddonRegistry"

rewardRowAddonRegistry.register({
    key: "hungry-beast",
    component: markRaw(BeastLootAddon),
    onClaimed: onBeastLootClaimed,
    settle: settleBeastLoot,
    dismiss: dismissBeastLoot
})
```

组件 props：`reward`、`area`（`"info"` | `"action"`）。不是自己盯的那份就什么都不渲染。

    `info` — 标题下面的说明（现行：🐕 小兽想要这份）
    `action` — 领取旁边的按钮（现行：喂养）
    `onClaimed` — 玩家点领取成功之后
    `settle` — 真正进入下一房间、结算还没领的奖励之前。没领算出喂写在这里，不要写进 `settlePendingRewards`
    `dismiss` — 界面关掉、列表清空

描边、悬停出按钮，样式写在插件自己的组件里。可以用 `.reward-row:has(...)` 画行框，不要给 RewardModal 加专用 class。

现行：小兽伙伴。`hungryBeast_registerInterceptor` 在 `beforeShowRewards` 盯一份，并注册 `BeastLootAddon`。霸占走 `blockClaim`。逻辑在 `src/ui/hooks/interaction/beastLoot.ts`。

## 前进和地图

点「前进」只打开地图，不清空奖励。关掉地图后没领完的还能领。真正点进下一个房间才 `settlePendingRewards`：先跑各插件的 `settle`，再自动领走金币等；药水栏满领不走的会跳过并记日志。
