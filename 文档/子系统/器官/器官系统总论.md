# 器官系统总论

器官是玩家角色与敌人的核心组成部件，同时具备"目标 Target"和"物品 Item"双重身份。核心循环由器官驱动：击败敌人 → 从敌人身上选取器官 → 器官提供卡牌与被动效果 → 组合出构建。

本文档给出器官系统全景。分主题细节见文末索引。

源文件：
    类：`src/core/objects/target/Organ.ts`
    修饰器：`src/core/objects/system/modifier/OrganModifier.ts`
    部位配置：`src/static/list/target/organPart.ts`
    类型：`src/core/types/OrganTypes.ts`

## 器官本质

`Organ extends Entity`。类型标识 `targetType: "organ"`。字段：

```typescript
class Organ extends Entity {
    key:          string           // 唯一 key
    label:        string           // 显示名
    rarity:       OrganRarity      // 稀有度（必填，影响吞噬量/售价/掉落）
    level:        number           // 等级（默认 1，可升级）
    part?:        OrganPart        // 部位（可选，不填不占部位）
    absorbValue:  number           // 吞噬获取量（不填走稀有度默认值）
    tags:         string[]         // 标签
    cards:        string[]         // 提供的卡牌 key
    cardsByOwner?:{                // 按持有者类型提供不同卡牌（见下）
        player?: string[]
        enemy?:  string[]
    }
    entry:        string[]         // 词条 key
    upgradeConfig?: OrganUpgradeConfig    // 升级里程碑
    activeAbilities?: ActiveAbility[]      // 主动能力
    badges?:      BadgeConfig[]            // 角标
    interaction:  Interaction[]            // 交互定义（下文详述）
    isDisabled:   boolean                  // 是否损坏
    isTemporary:  boolean                  // 是否临时器官
    temporaryRemoveOn?: "battleEnd" | "turnEnd" | "floorEnd"
}
```

## 交互 interaction

6 种交互 key，代码通过 `getInteraction(key)` 读取：

```
possess    始终生效——只要拥有器官就持续生效，损坏也不受影响
           用途：占据部位、无视损坏的固定被动

work       未损坏时生效——95% 的被动效果都用这个
           器官被拥有时 activateWorkTriggers 挂触发器，损坏时 removeWorkTriggers 撤下

broken     仅损坏时生效——损坏后的负面效果、自毁机制等
           器官损坏时 activateBrokenTriggers 挂触发器

get        获得器官时的一次性效果
lose       失去器官时的一次性效果
use        主动使用（损坏时无法使用）
```

`work` 与 `broken` 触发器的挂载/卸载完全自动，由 `OrganModifier` 在器官状态变化时驱动，不需要开发者手写清理。

交互内容结构详见 [[reaction-system-detail]]。

## 属性字段详解

### rarity 稀有度

`OrganRarity` 类型，值决定：

```
掉落权重          稀有度越高，敌人身上出现概率越低
吞噬获取量默认值  稀有度越高默认吞噬量越高（可被 absorbValue 覆盖）
黑市定价基线      详见 [[black-store-config-guide]] 的 calculateBlackStorePrice
```

具体稀有度枚举与掉落/定价曲线见 [[organ-rarity-tag-system]]。

### level 等级

默认 1。可在水池房间升级（详见 [[water-pool-action-system]]），升级根据 `upgradeConfig` 触发效果或里程碑：

```typescript
interface OrganUpgradeConfig {
    maxLevel?: number
    cost?:     number | ((organ) => number)  // 升级消耗（不填走稀有度默认）
    perLevel?: {                              // 每级都触发的效果
        effects: EffectUnit[]
    }
    milestones?: OrganUpgradeMilestone[]      // 特定等级里程碑
}

interface OrganUpgradeMilestone {
    level:         number
    effects?:      EffectUnit[]
    component?:    string | Component         // 自定义 UI
    componentData?: any
}
```

**注意**：器官的 `upgradeConfig` 与卡牌的 `upgradeConfig` **结构不同**——卡牌用 `levelConfigs[N]` 全量覆盖，器官用 `perLevel + milestones` 增量叠加。

### part 部位

不填 = 不占部位、可无限重复获取（如寄生虫）。

内置 13 种部位（`partConfigList`）：

```
Heart(心脏 max1)  Lung(肺 max2)  Liver(肝 max1)  Stomach(胃 max1)
Brain(脑 max1)    Eye(眼 max2)    Skin(皮 max3)   Bone(骨 max3)
Muscle(肌 max3)   Blood(血 max1)  Nerve(神经 max2) Gland(腺 max3)
Core(核心 max1)
```

任意字符串也能作为 part（未注册的默认 `maxCount = 1`）。Mod 用 `registerPart(config)` 扩展。

详细部位机制见 [[organ-part-system]]。

### mass 质量（生命值）

器官 mass 属性通过 `status["max-mass"] + current.mass` 表达（非器官类自带字段）。不定义 `max-mass` 的器官不吸收伤害、也不易损坏。

详细：[[organ-mass-system]]。

### absorbValue 吞噬获取量

吞噬/售卖时物质/金钱的基准值：

```
同化消耗       20% × absorbValue（数值以实际配置为准）
吞噬获得       absorbValue × level + rarity 加成
升级消耗       110% × absorbValue
修复消耗       60%  × absorbValue
售出金钱       按等级 × 稀有度定价（非 absorbValue）
```

具体倍率见 `src/static/list/target/organQuality.ts` 与配置文件。

## cardsByOwner 与对称原则

代码支持 `cardsByOwner: { player?: string[], enemy?: string[] }`，会覆盖 `cards`：持有者是 Player 时用 `cardsByOwner.player`，是 Enemy 时用 `cardsByOwner.enemy`。

设计原则：**优先用 `cards` 让所有持有者拿到相同卡牌**。这是本项目 Mod-First 架构的核心——一个器官一套逻辑，不因持有者而变。

`cardsByOwner` 是**允许的必要例外**，仅用于效果本质上只对一方有意义的情形（例如某张卡依赖玩家侧手牌堆机制）。它不应被用作"给 Boss 一个更强版本、给玩家一个更弱版本"的平衡工具。

## 行为 API

`Organ.ts` 直接导出 9 个包装函数，全部委托给 `OrganModifier`：

```typescript
getOrgan(entity, source, organ)                       // 获得
removeOrgan(entity, organ, triggerLoseEffect?)        // 失去（可选是否触发 lose 效果）
useOrgan(entity, organ, targets[])                    // 主动使用
breakOrgan(entity, organ)                             // 损坏
repairOrgan(entity, organ)                            // 修复
assimilateOrgan(entity, organ)                        // 同化（战斗结束选敌人器官）
devourOrgan(entity, organ)                            // 吞噬（拆自己器官换物质）
upgradeOrgan(entity, organ)                           // 升级
sellOrgan(entity, organ)                              // 售卖
```

具体条件（能否损坏/修复/售卖 = 场景/物质/等级判定等）走 `OrganModifier` 内部逻辑，不在包装函数暴露。
