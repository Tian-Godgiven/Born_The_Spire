# 事件房间 (Event Room)

事件是房间的一种，提供多种选项和随机事件的场所。

## 基本信息

在层级内，概率出现的特殊房间，每层的数量为3~7个。其中发生的事件会从当前层的事件池中抽取，不会重复。

事件具备不同的选项，对应产生不同的效果，可能具备随机性，这些效果都会显示在选项上，不会出现纯粹的惩罚性事件。事件能够提供的效果多种多样。

允许玩家通过SL的方式重置事件，但随机的结果并不会改变。

## 事件系统架构

事件房间由三个核心部分组成：

1. **事件配置 (EventMap)**：定义事件的标题、描述、图标和选项列表
2. **事件效果映射 (eventEffectMap)**：将效果 key 映射到具体的效果函数
3. **事件房间类 (EventRoom)**：管理事件的生命周期和选项交互

## 事件配置结构

```typescript
interface EventMap {
    key: string                     // 事件唯一标识
    title: string                   // 事件标题
    description: string             // 事件描述
    icon?: string                   // 事件图标
    options: EventOptionMap[]       // 事件选项列表
    component?: Component | string  // 自定义事件组件（可选）
}

interface EventOptionMap {
    title: string                   // 选项标题
    description: string             // 选项描述
    icon?: string                   // 选项图标
    effects?: Array<{               // 简单效果列表
        key: string                 // 效果 key（对应 eventEffectMap）
        params?: any                // 效果参数
    }>
    component?: Component | string  // 复杂交互组件（转盘、配对等）
    customCallback?: () => void | Promise<void>  // 自定义回调
}
```

## 事件类型

### 1. 简单效果事件

使用 `effects` 数组定义，每个效果通过 `eventEffectMap` 执行

```typescript
{
    key: "event_treasure_chest",
    title: "宝箱",
    description: "你发现了一个宝箱...",
    options: [
        {
            title: "打开宝箱",
            description: "获得随机奖励",
            effects: [
                { key: "gainMaterial", params: { amount: 100 } },
                { key: "gainRandomCard", params: { count: 1 } }
            ]
        }
    ]
}
```

### 2. 复杂交互事件

使用 `component` 指定自定义组件（如转盘、配对游戏等）

```typescript
{
    key: "event_gambling",
    title: "赌博",
    description: "一个赌徒邀请你参与一场游戏...",
    options: [
        {
            title: "参与赌博（花费 50 金钱）",
            description: "转动转盘，获得随机奖励",
            effects: [
                { key: "loseGold", params: { amount: 50 } }
            ],
            component: "RouletteWheel"  // 自定义转盘组件
        }
    ]
}
```

### 3. 自定义回调事件

使用 `customCallback` 执行复杂逻辑

```typescript
{
    title: "升级器官",
    description: "选择一个器官进行升级",
    customCallback: async () => {
        // 打开器官升级界面
        await openOrganUpgradeUI()
    }
}
```

## 事件房间生命周期

```typescript
// 1. 进入房间
await eventRoom.enter()
// 显示事件标题和描述，记录日志

// 2. 处理房间（UI 驱动）
await eventRoom.process()
// 玩家通过 UI 选择选项

// 3. 选项被选择
await eventRoom.onOptionSelected(option)
// 执行 effects、customCallback、或打开 component

// 4. 完成房间
await eventRoom.complete()
// 记录结束日志

// 5. 离开房间
await eventRoom.exit()
// 清理状态
```

## 注意事项

1. **选项必须有出口**：⚠️ 事件的选项/选项树最后必须导向一个"离开"选项，不要让玩家困在事件内无法退出。即使是多层选项树，也要确保每条路径最终都能离开事件房间
2. **效果执行顺序**：`effects` 数组中的效果按顺序执行，后续效果可能依赖前面效果的结果
3. **事件唯一性**：事件从池中抽取后不会重复出现（除非重置事件池）
4. **SL 机制**：玩家可以重置事件，但随机结果是固定的（全局随机种子系统尚未实现，见任务列表）
5. **选项组响应式**：`ChoiceGroup.choices` 是响应式数组，可以动态添加/移除选项
6. **自定义组件生命周期**：自定义组件需要自行管理与事件房间的交互

## 事件房间注册

位置：`src/static/registry/rooms/initEventRooms.ts`

### 类型注册

```typescript
import { EventRoom } from "@/core/objects/room/EventRoom"
import EventRoomVue from "@/ui/page/Scene/running/EventRoom.vue"
import { roomRegistry } from "../roomRegistry"

roomRegistry.registerRoomType("event", EventRoom, EventRoomVue)
```

### 配置注册

事件配置从 `eventList` 懒加载模块批量注册：

```typescript
import { getLazyModule } from "@/core/utils/lazyLoader"

const eventList = getLazyModule<EventMap[]>('eventList')

eventList.forEach(event => {
    roomRegistry.registerRoomConfig({
        key: event.key,
        type: "event",
        name: event.title,
        description: event.description,
        customData: {
            eventKey: event.key
        }
    })
})
```

### 添加新事件

在 `eventList.ts` 中添加：

```typescript
export const eventList: EventMap[] = [
    // 已有事件...

    // 新事件
    {
        key: "event_new",
        title: "新事件",
        description: "这是一个新事件",
        icon: "🎲",
        options: [
            {
                title: "选项1",
                description: "选择这个选项",
                effects: [
                    { key: "gainMaterial", params: { amount: 50 } }
                ]
            },
            {
                title: "选项2",
                description: "选择另一个选项",
                effects: [
                    { key: "healHealth", params: { amount: 20 } }
                ]
            },
            {
                title: "离开",
                description: "什么也不做",
                effects: [
                    { key: "nothing" }
                ]
            }
        ]
    }
]
```

配置会在应用启动时自动注册到房间注册表
