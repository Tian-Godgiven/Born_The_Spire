# 稀有度色板

器官、遗物、卡牌、奖励弹窗共用的稀有度名字和颜色。白底上能看清。

## 取值

只有三档：common / uncommon / rare

    common    普通  #333333
    uncommon  罕见  #2d5016
    rare      稀有  #1a3a6b

不要加 epic / legendary / normal。要扩档先改这张表，再改抽选和字段枚举。

## 用法

```typescript
import { getRarityLabel, getRarityColor } from "@/static/list/system/rarityPalette"

getRarityLabel(item.rarity)
getRarityColor(item.rarity)
```

模板里用 `:style="{ color: getRarityColor(item.rarity) }"`，不要在组件里再写对照表。

器官数值（吞噬量、升级倍率）仍在 `organQuality.ts`。那份表的 label / color 从色板读。
